# 📬 Message Board

A simple message board application built as a joint project by two brothers — backend and frontend.

---

## 🚀 Tech Stack

- Node.js — runtime
- Express.js — web framework
- EJS — templating engine
- HTML / CSS — structure and styling
- CSS animations — hover and click effects

---

## 📋 Features

- View all messages
- Add a new message (name + text)
- View each message individually
- Responsive design (mobile + desktop)
- Button animations (hover + active states)
